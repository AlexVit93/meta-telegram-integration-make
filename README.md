# Автоматизация интеграции Meta Ads в Telegram

## Обзор проекта
В данном репозитории представлена готовая архитектура интеграционного решения для автоматической передачи данных из рекламного кабинета Meta Ads (Facebook Lead Ads) в рабочие чаты Telegram с использованием платформы Make (Integromat). Решение обеспечивает мгновенную доставку лидов без необходимости ручного переноса данных.

## Архитектура решения

### Логика сценария в Make (Integromat)
Вся конфигурация и логика маршрутизации данных содержатся в приложенном файле `blueprint.json`. Сценарий включает в себя следующие этапы обработки:
* Триггер: Интеграция через вебхук Meta Graph API (`facebook-lead-ads:watchLeads`), который перехватывает входящие лид-формы в режиме реального времени.
* Валидация данных: Модуль маршрутизации (Router), проверяющий наличие обязательного контактного поля (номер телефона) перед отправкой.
* Действие: Вызов Telegram Bot API (`telegram-bot-api:sendMessage`), который формирует структурированное текстовое уведомление и отправляет его в целевой чат.

## Структура репозитория
* `blueprint.json` — экспортированная схема автоматизации со скрытыми персональными токенами и идентификаторами.
* `README.md` — техническое описание проекта и руководство по развертыванию.

## Инструкция по развертыванию
1. Создайте новый пустой сценарий в панели управления Make.com.
2. В меню настроек выберите опцию "Import Blueprint" и загрузите файл `blueprint.json`.
3. Подключите модуль Facebook Lead Ads к вашему аккаунту Meta Business Suite.
4. В модуле Telegram укажите ваш API-токен бота и идентификатор целевого чата (Chat ID).
